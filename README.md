# 🚀 MG ZAN PRO
**Advanced Network Testing Tool for Termux**

This tool is designed for high-speed network authentication testing using Python's asynchronous engine.

## 🛠 Installation

Copy and paste these commands in your Termux:

```bash
pkg update && pkg upgrade -y
pkg install python git -y
pip install aiohttp requests
git clone [https://github.com/zarni1mobile122005-sudo/Mg-Zan-Pro](https://github.com/zarni1mobile122005-sudo/Mg-Zan-Pro)
cd Mg-Zan-Pro
python mg_zan.py
